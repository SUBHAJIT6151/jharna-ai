# Jharna AI Starter Kit

A personal AI chat application built with Node.js,
Express and Google Gemini API.

## Requirements
- Node.js
- npm
- Google Gemini API Key

## Installation

1. Extract this ZIP.
2. Install dependencies:

   npm install

3. Create a file named .env
4. Add your own Gemini API Key:

   GEMINI_API_KEY=YOUR_API_KEY

5. Start the application:

   node index.js

6. Open http://localhost:3000

## Render Deployment

Build Command:
npm install

Start Command:
node index.js

Environment Variable:

Key: GEMINI_API_KEY
Value: Your own Gemini API Key

## Important

Never share your real API Key.
Create your own GitHub repository and Render service.
